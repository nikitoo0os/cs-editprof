# Weapon UI assets

The SVG files under `src/Cs2Highlight.Web/wwwroot/assets/weapons` are original,
project-authored geometric UI glyphs created for this repository. They contain
no copied game textures, logos, skins, or third-party artwork and are licensed
under the same license as this repository.

They are descriptive interface symbols only. Unknown or untrusted parser input
always maps to `unknown.svg`; filenames are selected by the server-side weapon
catalog and are never built from request data.
